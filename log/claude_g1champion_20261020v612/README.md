# G1 チャンピオン v6.12（2026-10-20）── v6.11 + MPC の交差の一歩（`MPC_FOOTSTEP_CROSS_*`）

`controls.json` = v6.11（`log/claude_g1champion_20261020v611/`）に
`MPC_FOOTSTEP_CROSS_Y=0.20 MPC_FOOTSTEP_CROSS_FLOOR=0.5 MPC_FOOTSTEP_CROSS_HOLD_Z=0.05 MPC_FOOTSTEP_CROSS_EX=0.03` を加えたもの。
URDF・参照 3 本は同じ（同梱、`REF_LIBRARY` は本ディレクトリ）。バイナリは `kyo46rs_walk_tu34`（v6.11 の tu29 以降に STAIR_ZONE_SWING_ROT・MPC_TRAJ_CSV／PREVIEW_TRAJ_CSV・DS_CAPTURE_LAT・MPC_FOOTSTEP_CROSS_* と、MPC の着地の箱が負の下限を捨てていたバグの修正が入った。いずれも既定・非負の箱ではビット同一を cmp で確認）。

- 門（`_CROSS_EX=0.03`）: 片脚支持中に DCM が支持足の中心から外へ 3 cm を越えたら、その片脚支持の間、着地の内側の上限を 0.20 m に開く（v6.11 は内側 0、`MPC_FOOTSTEP_MAX_Y_IN=0`）。向きは門を開いた時点で固定。
- 下限（`_CROSS_FLOOR=0.5`）: 支持足の外縁に CoP を置いた LIPM で着地時の DCM を予測し、着地がその足裏半幅の半分以内に入るよう内側の補正量に下限を課す。単一剛体に向きが無く、MPC だけでは必要量の半分しか動かさないため。
- 高さ保持（`_CROSS_HOLD_Z=0.05`）: 交差中、遊脚が着地点から水平 2 cm より遠い間は着地面から 5 cm 以上に保つ（予定時刻に手前で着いて滑るのを防ぐ）。
- 機構: v6.11 の横押しの転倒 24 本中 21 本が遊脚位相 0.58〜0.75 の支持足側の押しで、着地点が動かず DCM が縁の 9〜11 cm 外（`doc/from_claude/20261014_push_x_speed.md` §16〜17）。
