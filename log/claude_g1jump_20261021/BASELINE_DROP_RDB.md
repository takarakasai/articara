# G1 台から跳び降りるの基準 RDB（2026-11-14、ユーザ確定）

高さ 10〜50 cm の台の上から、前の縁の先へ一つの設定で跳び降りて立つ。台から跳び降りる候補はこれと比べる（DD＝`BASELINE_DROP_DD.md` を置き換える。10〜20 cm は DD とビット同一）。

- バイナリ: `g1_flight_probe_base_rdb`（= j83、articara 6b3f9dc、misa-locomotion def96db）。LAND_HOLD/RISE_DROP・LAND_RISE_DROP_H・LAND_RISE_DROP_DECEL を足した版で、未設定なら base_dd と同一。
- 設定: DD（`jb82.sh` の `dn()` に `"KP_TRUNK_LAND_DROP":"60","KD_TRUNK_LAND_DROP":"150"`）に `"LAND_HOLD_DROP":"0.1","LAND_RISE_DROP":"0.7","LAND_RISE_DROP_H":"0.25","LAND_RISE_DROP_DECEL":"0.65"` を足したもの（`jb94.sh` の `VB`）。
  - 離地した面より 25 cm を超えて低い面への着地だけ、沈みの保持を 0.3 → 0.1 s、立ち上がりを 1.0 s の 5 次から「加速 0.35 s＋減速 0.65 s」（休止から休止の 5 次の前半と後半を最高速度でつなぐ）にする。
  - 深く沈んだままの時間を縮めて立ち上がりで重心が後ろへ戻るのを防ぎ（最初の着地の後の転倒 27 → 5）、減速を緩めて片足が浮いて広く置き直されるのを防ぐ（足の浮き 272 → 3、直しの跳躍の後の転倒 44 → 23）。
  - 25 cm 以下の着地・平地・台への跳躍には掛からない（cmp で DD と同一）。台なしは DD と同じ 142／144。
  - 台: `"JUMP_BOX":"<e-2>,<高さ>,2.0"`、e = 0.13 + 間合い g、狙いは `JUMP_FWD_TARGET` = g + 0.25（DD と同じ）。
- 実行例: `jb94.sh`（種 27182 N=16 の `RDB_{30,40,50}_{02,05,10}`、種 16180 N=8 の `RDBh…`）、`jb95.sh`（新しい種 31415 N=8 の `RDBp…`、DD の `DDp…`）。10〜20 cm は DD の `jb82.sh`・`jb84.sh`。集計は `dnsumm.py`、同じ本どうしは `jrand.py cmp`。

各欄は立って終えた本の数（2 つの種 27182・16180 の合計、各 24 本）。括弧は DD。

- DD と同じ本どうし（30〜50 cm、432 本）: 改善 56・悪化 13（z +5.18）。新しい種 31415（144 本）: 110 → 124、改善 21・悪化 7（z +2.65）。

- 既知の限界:
  - 離地の弱い本は最初の着地が縁の上か台の上になる（30〜50 cm で 26 本、DD と同じ本）。
  - 最初の跳躍は降りる高さに比例して狙いを越え、後ろへの直しの跳躍の後に倒れる本がある（23 本、FY の後ろへの跳躍の弱さ）。
  - 2.0・間合い 0.05 の 30 cm が 17／24 と低い。
