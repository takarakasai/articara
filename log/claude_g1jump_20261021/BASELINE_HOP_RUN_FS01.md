# G1 止まらない左右交互の片足跳びの基準 FS01（2026-11-21、ユーザ確定）

止まらない交互の片足跳び（着地の直後に次を押す、HOP_RUN）の最初の基準。その場で左右の足を入れ替えながら跳び続け、最後に片足で立ち止まる課題の候補は、これと比べる。止まる構造の片足跳びは HVX（`BASELINE_HOP_REPEAT_HVX.md`）のまま。

- バイナリ: `g1_flight_probe_base_fs01`（= j106、articara 458dd38、misa-locomotion def96db）。
- 設定: `jb142.sh` の `hr` と `FS01`（`jb112.sh` の `X`・`H`・`HP` に次を足したもの）:
  - `"HOP_LEG":"L"|"R"`: 最初の支持足。`"JUMP_REPEAT":"9","T":"20"` で 10 回跳ぶ。
  - `"HOP_ALT":"1","HOP_ALT_W":"0.18","HOP_ALT_VY":"0.15","HOP_ALT_LEAN_Y":"0","HOP_FLIGHT_Y_CAPTURE":"1.0"`: 左右交互（§55）。
  - `"HOP_RUN":"1","HOP_RUN_T_CROUCH":"0.25","HOP_RUN_XI":"0.07","HOP_RUN_DCM":"0","HOP_RUN_CAPTURE_X":"0.8"`: 止まらない（§56）。着地 0.04 s 後に再始動、立ちの横は CoP を選ぶ計画、空中で新しい支持足を捕獲点へ。
  - `"FLIGHT_TRUNK":"1","WBCW_TRUNK_PUSH":"0.3"`: 押しと空中で胴を保つ（§57。X・H の 0 と 0.003 を上書き）。
  - `"HOP_FREE_X_W":"0.3"`: しゃがみから離地まで、遊脚の x を重心の x へ（§57）。
  - `"JUMP_VX":"0.2"`: 後ろへのずれを打ち消す（§57）。
  - `"HOP_RUN_STOP_DY":"0.01"`: 最後の着地だけ、基準を遊脚側へ 1 cm（§57 の続き）。
  - そのほか `"HOP_MOM_LAND_W":"0.1","HOP_CROUCH_DY":"0","FLIGHT_FEET_YAW":"1","HOP_FEET_YAW_FROM":"2","FLIGHT_TRUNK_YAW":"1"`。
- 集計は `runhops.py`（続けて着地した回数。最後の 1 回は立ち止まれたときだけ数える）。

- 既知の限界:
  - 摩擦 0.66 未満で倒れる（25 本中 8 本。0.66 以上は 55 本中 1 本）。1〜2 回目の離地で −0.1〜−0.24 m/s 後ろへ出て、3 回目に崩れる。
  - その場だけ（前後の速さは JUMP_VX の固定値で合わせている）。10 回で前後のずれは数 cm。
  - 1 周期は約 0.75 s（空中 0.22 s、立ち 0.5 s）。
