# G1 台から跳び降りるの基準 BF6（2026-11-15、ユーザ確定）

高さ 10〜50 cm の台の上から、前の縁の先へ一つの設定で跳び降りて立つ。台から跳び降りる候補はこれと比べる（RDB＝`BASELINE_DROP_RDB.md` を置き換える）。

- バイナリ: `g1_flight_probe_base_bf6`（= j84、articara efe24d8、misa-locomotion def96db）。JUMP_FWD_BACK_V を足した版で、未設定なら base_rdb と同一。
- 設定: RDB（`jb94.sh` の `VB`）に `"JUMP_FWD_BACK_V":"1.5","JUMP_FWD_DROP_TAB":"0.1:-0.06"` を足したもの（`jb99.sh` の `F6`）。
  - `JUMP_FWD_BACK_V` 1.5: 位置を狙う跳躍のうち後ろ向き（残り < 0）の跳躍だけ初速 1.5 で跳ぶ（表も 1.5 で引く）。越えすぎを直す後ろへの跳躍を 2.0 の高い跳躍でしていたのが、直しの跳躍の後の転倒の根だった（2.0 で 39 → 7、3 つの種・10〜50 cm）。1.5 の本は物理が変わらない。
  - `JUMP_FWD_DROP_TAB` 0.1:−0.06: 台の上からの最初の跳躍だけ狙いを 6 cm 遠くへ（表は高さで頭打ちなので 10〜50 cm すべて）。離地の弱い本が縁か台の上に着くのを防ぐ（44 → 5）。越えすぎの分は後ろへの跳躍が戻す。
  - 台: `"JUMP_BOX":"<e-2>,<高さ>,2.0"`、e = 0.13 + 間合い g、狙いは `JUMP_FWD_TARGET` = g + 0.25（DD・RDB と同じ）。
- 実行例: `jb99.sh`（30〜50 cm、種 27182 N=16 の `BF6_{h}_{g}`、種 16180 N=8 の `BF6h…`、新しい種 31415 N=8 の `BF6p…`）、`jb100.sh`（10〜20 cm）。BACK_V だけの BV15 は `jb97.sh`・`jb98.sh`（2.0 だけ）。集計は `dnsumm.py`、同じ本どうしは `jrand.py cmp`。

各欄は立って終えた本の数（2 つの種 27182・16180 の合計、各 24 本）。括弧は RDB。

- 10〜50 cm の合計 693 of 720（RDB 639、BV15 661）。
- BV15（RDB＋BACK_V 1.5）と同じ本どうし: 2 つの種の 10〜50 cm で改善 56・悪化 24（z +3.58）。新しい種 31415 の 30〜50 cm（144 本）: BV15 134 → 142、RDB 124。
- 2 つの種の 10〜50 cm の損 27 本の内訳: 最初の着地の後に倒れる 10、直しの跳躍の後に倒れる 12、最初の着地が縁か台の上 5。
- 既知の限界:
  - 2.0 の 40〜50 cm で強く前へ跳んだ本（着地の vx 0.56〜0.71 m/s）が最初の着地の後に倒れる（BV15 の 1 → 7）。遠く狙う量は高さだけで決まり、初速で変えていない。
  - 押しの終わりに片足の力が抜ける弱い離地（§47、摩擦の低い条件に多い）は残る。遠くを狙って縁を越えさせているだけ。
  - 直しの跳躍の後の転倒は残り −0.08〜−0.16 m の 1 回の跳躍の後。
