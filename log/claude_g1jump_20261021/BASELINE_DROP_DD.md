# G1 台から跳び降りるの基準 DD（2026-11-14、ユーザ確定）

高さ 10〜50 cm の台の上から、前の縁の先へ一つの設定で跳び降りて立つ。台から跳び降りる候補はこれと比べる（初めての跳び降りの基準）。

- バイナリ: `g1_flight_probe_base_dd`（= j75、articara 8e8f10f、misa-locomotion def96db）。KP/KD_TRUNK_LAND_DROP と LAND_DROP_H を足した版で、未設定なら base_fy と同一。
- 設定: `jb82.sh` の `dn()` に `"KP_TRUNK_LAND_DROP":"60","KD_TRUNK_LAND_DROP":"150"` を足したもの（`DD`）。
  - 離地した面より 5 cm（LAND_DROP_H）以上低い面への着地だけ、胴の着地のゲインを 60/150 にする。平地と台への跳躍には掛からない（平地は cmp で FY と同一）。
  - FY のままだと 30 cm 以上で着地の沈みが深く（重心 0.41〜0.44 m、平地 0.57）、立ち上がる間に重心が足裏の中心より 5〜8 cm 後ろへ流れて後ろへ倒れる（§36 と同じ形）。
  - 残りは平地の位置を狙う跳躍の基準 FY（`BASELINE_FWD_TARGET_FY.md`）のまま: JUMP_FWD_TAB・JUMP_REPEAT 5・FLIGHT_FEET_YAW ほか。着地の面の高さは LAND_GROUND_Z（JUMP_BOX があると既定で有効）が合わせる。
  - 台: `"JUMP_BOX":"<e-2>,<高さ>,2.0"`（台が足より後ろなので台の上から始まる）。e は前の縁の x で、起点の爪先 0.13 から間合い g（0.02／0.05／0.10）。狙いは `JUMP_FWD_TARGET` = g + 0.25（踵が縁を越えるには g + 0.17 進む）。
- 実行例: `jb82.sh`（種 27182 N=16 の `DD{10..50}_{02,05,10}`）と `jb84.sh`（種 16180 N=8 の `DDh…`、FY のままの `DNh…`）。集計は `dnsumm.py`、同じ本どうしは `jrand.py cmp`。

- 台なし（同じ設定、ゲインは掛からない）は 142／144。
- FY のままと同じ本どうし: 種 27182 は改善 157・悪化 4、種 16180 は改善 86・悪化 4。悪化は各高さ 0〜2 本。
- 既知の限界:
  - 間合い 2 cm・初速 1.5 の 40〜50 cm（24 本中 11・9）。最初の着地から 1.3〜2.6 s 後に後ろへ倒れる。
  - 最初の跳躍は降りる高さに比例して狙いを越え（10 cm で +3 cm、50 cm で +10 cm）、後ろへの直しの跳躍の後に倒れる本がある（FY の後ろへの跳躍の弱さ）。
  - 離地の弱い本は最初の着地が縁の上か台の上になる（種 16180 では各高さ 4〜5 本、そこから跳び直して立つ本もある）。
  - 越えすぎは後ろの足が縁を越えるのに要る速さそのもの。狙いを縮めると重心ごと縁の手前に降りる（JUMP_FWD_DROP_TAB、jb83、228→48）。
