# G1 平面の位置を狙う跳躍の基準 PT（2026-11-15、ユーザ確定）

前後と横の狙った位置へ連続の跳躍で動いて止まる跳躍の候補は、これと比べる。横だけを狙う跳躍（§49）の基準も兼ねる。前後だけの狙いは FYB（`BASELINE_FWD_TARGET_FYB.md`）のまま。

- バイナリ: `g1_flight_probe_base_pt`（= j89、articara 526c4d2、misa-locomotion def96db）。JUMP_VY・JUMP_LAT_TARGET・JUMP_PLANE_SEQ を足した版で、どれも未設定なら base_bf6 と同一（cmp）。
- 設定: `jb111.sh` の `P` と `pt()`。FYB（X・H・TB・R＋JUMP_FWD_TAB・JUMP_FWD_BACK_V 1.5）に次を足したもの:
  - `"LAND_REF_SOLES":"0.5"`: 着地の基準を 0.5 s で足裏の中点へ運ぶ（横の着地の滑りを止める、台への跳び乗りの基準と同じ）。前後だけの狙いは変えない（318 of 320、FYB 318）。
  - `"JUMP_LAT_TAB":"<jb105 の LT>"`・`"JUMP_LAT_TARGET":"<y>"`: 1 回の跳躍の横の移動の表（JUMP_VY ±0.3〜0.6 → ±0.03〜0.14 m、2.0 は |VY| < 0.4 を 0 に）の逆引きで横の残りを詰める。
  - `"JUMP_PLANE_SEQ":"1"`: 横を先に、前後の移動 0 の倍率で詰めてから前後を。立ち直しのたびに両方を見直し、両方が許容（±5 cm）に入って止まる。
  - `"JUMP_REPEAT":"8","T":"36"`（跳ぶ回数が増えるため）。
- 実行例: `jb110.sh`（種 27182・16180 の `DTY…`・`DTZ…`）と `jb111.sh`（種 31415 の `DTP…`・`FTP…`）。集計は斜めの両軸の誤差を見るスクリプト（§50）。

各欄は立って終えた本 of 16。立って終えた本はすべて両方の軸で ±5 cm 以内（最大 5.0 cm）。

- 3 つの種で 463 of 480。同時に両方を詰めると（JUMP_PLANE_SEQ なし、種 27182・16180）234 of 320（PT 306）。
- 横だけ（種 31415、(0, ±0.3)）は 64 of 64、2〜5 回。種 27182・16180 の横だけの 5 つの狙い（±0.1〜0.5 m）は 308 of 320（jb106 の LS）。
- 既知の限界:
  - 摩擦の低い決まった条件（種 27182 の m01、μ 0.61・質量 1.04 倍）は 2.0 の最初の横への跳躍で倒れる。着地から重心が後ろへ流れ続ける。どの着地のノブでも直らない。
  - 種 16180 の 2.0 の斜めは 70 of 80。
  - 1 回の横の移動は ±0.14 m まで（JUMP_VY 0.8 から押しの終わりが後ろの足だけの二峰）。遠い狙いは跳ぶ回数で稼ぐ。
