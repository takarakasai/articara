# G1 前へ進む止まらない交互の片足跳びの基準 V20（2026-11-21、ユーザ確定）

左右の足を入れ替えながら、前へ 0.2 m/s（実際は 0.17 m/s）で跳び続け、最後に片足で立ち止まる課題の最初の基準。前へ進む交互の跳躍の候補は、これと比べる。その場の交互の跳躍は FS01（`BASELINE_HOP_RUN_FS01.md`）のまま。

- バイナリ: `g1_flight_probe_base_v20`（= j107、articara af8a1d3、misa-locomotion def96db）。
- 設定: FS01（`jb142.sh` の `hr`＋`HOP_RUN_STOP_DY 0.01`）に次を足したもの（`jb145.sh`／`jb146.sh` の `V20C06_*`）:
  - `"HOP_RUN_VX":"0.2"`: 再始動のしゃがみの x の基準を、着地の速さから 0.2 m/s へ移して進める。空中で次の支持足を、重心の前の 0.5×前の立ちの時間×0.2 m に置き、さらに捕獲で速さの誤差を返す（§58）。
  - `"HOP_RUN_CAPTURE_X":"0.6"`: 速さの誤差の捕獲（FS01 の 0.8 では、一歩ごとに速さが交互に振れる。§58 の続き）。
- 集計は `runspeed.py`（`runhops.py` と同じ数え方に、離地の前後の速さと 10 回で進んだ距離を足したもの）。

- 対の比較: FS01（その場）に +9／−1（z +2.53）。
- 測った値: 離地の前後の速さは中央値 +0.17 m/s（狙いの 85%）。1 周期 0.73 s（空中 0.21 s）。10 回目までの横のずれは中央値 −0.06 m（10〜90%: −0.12〜+0.11 m）。摩擦 0.66 未満でも 25 本中 24 本が立つ（FS01 の弱点だった）。
- 既知の限界:
  - 0.3 m/s では 250 / 320、10 回跳んで立つのは 6 / 32。離地のピッチの角運動量が +0.6 前後（その場は +0.44）で、骨盤が前へ傾いていき、6〜7 回目に崩れる。胴の重み・JUMP_VX では動かない（§58 の続き 2）。
  - 速さは一定。途中で変えたり、止まる一歩はない（最後の立ちは HOP_RUN_STOP_DY だけ）。
