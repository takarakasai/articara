# G1 着地の位置を狙う跳躍の基準 FYB（2026-11-15、ユーザ確定）

狙った距離だけ前（または後ろ）へ動いて止まる跳躍の候補は、これと比べる（FY＝`BASELINE_FWD_TARGET_FY.md` を置き換える）。

- バイナリ: `g1_flight_probe_base_bf6`（= j84、articara efe24d8、misa-locomotion def96db）。台から跳び降りるの基準 BF6 と同じ。
- 設定: FY（`jf3.sh` の X・H・TB・R＋JUMP_FWD_TAB・JUMP_FWD_TARGET）に `"JUMP_FWD_BACK_V":"1.5"` を足しただけ。
  - 後ろ向き（残り < 0）の跳躍だけ初速 1.5 で跳び、JUMP_VX_TAB・JUMP_LEAN_TAB・CROUCH_TAB・JUMP_FWD_TAB も 1.5 で引く。最初の跳躍の狙いが負（−0.3 m）のときも掛かる。
  - 1.5 の本は物理が FY と同じ（表示の行だけ違う、cmp）。
- 実行例: `jb97.sh` の `fy()`（2.0 だけ、種 27182 の `BVY…`、種 16180 の `BVZ…`）。1.5 は FY の `FY…`・`FZ…`（`jf3.sh`・`jf4.sh`）。

各欄は立って終えた本 of 16。括弧は FY。立って終えた本はすべて ±5 cm 以内（最大 4.9 cm）。

  - 1.5 の +1.0 m で各 1 本倒れる（FY と同じ）。
