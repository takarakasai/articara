# G1 前への跳躍の基準 TB6（2026-11-07、ユーザ確定）

前への跳躍の候補はこれと比べる（前の基準は TB5、`BASELINE_FWD_TB5.md`）。TB5 に、回す連続の跳躍（§29）で入れた 2 つの直しを足したもの。垂直跳びの基準 TV3R とは別。

- バイナリ: `g1_flight_probe_base_tb6`（= j51、articara 6163fd9、misa-locomotion def96db）。TB5 の設定では TB5 のバイナリ（j34）と run.log がバイト一致。
- 設定: TB5 の設定に `"MU_TORSION":"0.02","TRUNK_RP_YAWED":"1"` を足す。
  - `MU_TORSION`: QP のねじりの上限 |mz| ≤ μ fz（既定 0.05）。G1 の足裏は床と 2 点で接するので、0.05 では着地後に足が床の上でねじれる。
  - `TRUNK_RP_YAWED`: 胴のロール・ピッチの誤差をヨーで世界の軸へ回す（`bt::trunk_rp_ref` はヨー 0 前提）。
  - 実行例は `jt20.sh` の TBM。集計は `summ.py TB6 の比べ先 候補`。
