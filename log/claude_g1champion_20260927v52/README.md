# G1 チャンピオン v5.2（2026-09-27）── v5.1 + 着地の辞書式決定（捕捉を罰則でなく優先順位で）

`controls.json` = v5.1（`log/claude_g1champion_20260927v51/`）に `MPC_LANDING_LEX=1` を加えたもの。URDF は同じ（同梱）。

v5.1 までは着地の捕捉を重み 1e6 の罰則で効かせていた（1e4 で歩き出しに転倒、1e5 で段崩壊、1e7 で全滅という刃の上）。
v5.2 は着地を 2 段で決める:
1. 箱の中で捕捉残差を最小にする着地を厳密に解く（着地 2 変数の箱付き QP、端点列挙。`wrench_mpc::lexicographic_landing`）。
2. その着地を等式制約で固定して、レンチの MPC を解く。
捕捉重み →∞ の極限にあたり、重みは捕捉の入力を有効にするだけになった（1e4〜1e7 で軌跡がビット同一）。

バイナリは同梱（`kyo46rs_walk`、コミット時点の作業ツリーから `--no-default-features --features mujoco` でビルド）。
