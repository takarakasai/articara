# G1 チャンピオン v5.1（2026-09-27）── v5 + 前向き DCM 誤差のときだけ内側への横ステップを許す

`controls.json` = v5（`log/claude_g1champion_20260927v5/`）に次の 2 つを加えたもの。URDF は同じ（同梱）。

| 設定 | 値 | 役割 |
|---|---|---|
| `MPC_FOOTSTEP_Y_IN_FWD` | 0.035 | 前後の DCM 誤差が前向きのとき、内側（支持脚側）への横シフトを 35 mm まで許す |
| `MPC_FOOTSTEP_Y_IN_FWD_TRIG` | 0.005 | その判定の閾値（ξx − ξx_ref ≥ 5 mm） |

v5 は内側を常に 0 にしており、後ろ押しは守れたが 11 N·s 前押しの回復を削っていた。前押しでは押された歩で
着地を前へ出すと同時に内側へ 20–35 mm 寄せるのが回復の形で、害になる内側修正（後ろ押しの後）は前後誤差が後ろ向きか
ほぼ 0 のときに起きる。前後誤差の向きでこの 2 つを分ける。

バイナリは同梱（`kyo46rs_walk`、コミット時点の作業ツリーから `--no-default-features --features mujoco` でビルド）。
