# G1 チャンピオン v5（2026-09-27）── v4.1 + MPC の着地変数（捕捉行・計画感度・閾値武装・内側禁止）

`controls.json` = v4.1（`log/claude_g1champion_20260927v41/`）に次を加えたもの。URDF は v4.1 と同じ（同梱）。

| 要素 | 設定 | 役割 |
|---|---|---|
| 着地変数 | `MPC_FOOTSTEP=1`、`MPC_FOOTSTEP_W=100`、箱 `MAX_X=0.15`／`MAX_Y=0.08` | 遊脚の着地を重心 MPC の決定変数にする |
| 捕捉行 | `MPC_LANDING_CAPTURE_W=1e6` | 地平内で DCM を伝播し、着地が次の圧力点として DCM を捕捉するよう解く |
| 計画感度 | `MPC_LANDING_CAPTURE_J=1` | 着地を動かすと計画の参照 DCM も動く分（≈0.65 dp）を入れ、解の交互反転を消す |
| 閾値武装 | `MPC_FOOTSTEP_TRIG=0.015` | DCM 誤差 15 mm に達した歩だけ着地変数を使う（平穏な歩は v4.1 と同一の問題） |
| 内側禁止 | `MPC_FOOTSTEP_MAX_Y_IN=0` | 支持脚側への横ステップを禁じる（v4.1 の `CP_MAX_Y_IN=0` と同じ規則） |
| 時間調整 | `CONTACT_PLAN=1` のまま `CP_MAX_X=CP_MAX_Y=CP_MAX_Y_IN=0` | 発見的調整は再計時だけ。位置は MPC、時間は contact_plan |

バイナリは同梱（`kyo46rs_walk`、コミット時点の作業ツリーから `--no-default-features --features mujoco` でビルド）。
