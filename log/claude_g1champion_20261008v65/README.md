# G1 チャンピオン v6.5（2026-10-08）── v6.4 + 軌道最適化の回復参照（`REF_LIBRARY`）＋押しの検出

`controls.json` = v6.4（`log/claude_g1champion_20261004v64/`）に次の 4 ノブを加えたもの。URDF は同じ。**バイナリは新しい**（同梱 = `kyo46rs_walk_ref13`）。
参照 3 本（`ref_*.json`）も同梱で、`REF_LIBRARY` はこのディレクトリの相対パス（リポジトリのルートから走らせる）。

- `REF_LIBRARY`: `scripts/trajopt/push_recovery.py` で解いた回復の参照（重心動力学＋全身運動学、トルク限界 90%、脚の衝突、支持足の前を越える交差、
  公称の立ち幅で終わる、検出遅れ 80 ms を初期状態に含む）。歩行中 0.12 m/s・支持足側へ 5 N·s（遊脚の位相 0.3 と 0.5 向け）と 7 N·s（0.3 向け）。
- `REF_TRIG_DCM=0.036`: 片脚支持中、支持足側への横 DCM 誤差が 36 mm を超えたら参照を当てる（4 N·s 以下の押しは歩容が自分で立つので掛からない閾値）。
- `REF_DELAY_COMP=0`: 検出時に参照の先頭から入る（参照が検出遅れを含んでいるため）。
- `REF_TRIG_MAX_FRAC=0.65`: 遊脚の位相 0.65 以降の押しには当てない（そこは歩容が自分で立つ）。

参照が当たる間: 歩容の相の長さと次の 2 歩の足場を参照に合わせ、遊脚は参照の足裏軌道を追い、接触計画・MPC の着地変数・DS の再計時は止まり、
着地は実測の接地（`CONTACT_EVENT` の規則）で取る。参照の後は両足の中点に公称幅で足場を置き直して通常の歩容へ戻る。
