# G1 チャンピオン v6.13（2026-10-21）── v6.12 + 後ろ押しの後の計画の作り直し

`controls.json` = v6.12（`log/claude_g1champion_20261020v612/`）に
`MPC_FOOTSTEP_SHIFT_REST=1 MPC_FOOTSTEP_HOLD_SHIFT=0.06 MPC_FOOTSTEP_CAPTURE_FLOOR=0.5 MPC_FOOTSTEP_BACK_ONLY=1 MPC_FOOTSTEP_BACK_PERSIST=0` を加えたもの。
URDF・参照 3 本は同じ（同梱）。バイナリは `kyo46rs_walk_tu38`（tu34 以降に MPC_FOOTSTEP_SHIFT_REST・PLAN_REANCHOR_TD・HOLD_SHIFT・BACK_ONLY・BACK_PERSIST と、感度 J を shift_rest で測る切替が入った。未設定で tu34 とビット同一を押し・階段の各 1 本で cmp 確認）。

全部品は「DCM が参照より 2 cm 以上後ろ、かつ横の誤差より大きい」とき（`BACK_ONLY`）だけ働く。
- `SHIFT_REST`: MPC が着地を動かしたら、その先の足跡も同じだけ動かす（押しの前の梯子へ戻らず、動かした着地から歩き直す）。MPC に渡す感度 J も同じ動かし方で測る。一度使った片脚支持の間はラッチ。
- `CAPTURE_FLOOR=0.5`: x の捕捉の下限（LIPM で着地時の DCM を予測し、足裏の後端が届くよう着地の後ろへの補正に下限）。MPC の着地の箱が負の下限を捨てていたバグ（v6.12 で修正）以前は効いていなかった。
- `HOLD_SHIFT=0.06`: 着地を 6 cm 以上後ろへ動かした遊脚は、着地点に近づくまで 5 cm の高さを保つ（予定の時刻に手前で下りない）。
- 機構: 後ろ 14 N·s の転倒は早い位相の押しで着地が支持足の真横になり、DCM を捕まえても次の一歩が押しの前の前進計画どおり前へ出て倒れていた（`doc/from_claude/20261014_push_x_speed.md` §18〜19）。
