# G1 の走りの基準 WR08（2026-11-23、ユーザ確定＝§73 の案 1）

WR07（`BASELINE_RUN_WR07.md`）の走りに、交差の場面で立ちを保つ規則を足す。走りの候補はこれと比べる。

- 設定: `wr08.sh` = `wr07.sh` ＋ `CP_RUN_CROSS_HOLD=0.02`。
  - `CP_RUN_CROSS_HOLD`（misa-biped `walker/phases.rs`、ContactPlan の直後）: 走りで、計画に対する DCM の横の誤差（進行方向の座標）が支持足の側へ 0.02 m を超えたら、ContactPlan の選んだ終わりの代わりに計画の終わりで立ちを終える。延ばす倍率 `CP_RUN_CROSS_EXT` は 1.0（既定）。1.3 も損はなく、差は小さい（§73）。遊脚の側へずれたときは ContactPlan のまま（縮めてよい）。
  - 乱れのない走りでは働かない。名目の 12 本は WR07 と軌道が一致する。
- バイナリ: `log/claude_g1rand_20260925/kyo46rs_walk_tu83`。articara の Cargo.toml の misa-mpc／misa-biped は misa-locomotion 4ba73ef（push 済み）。tu82（手元を差し込んだもの）と軌道が一致（走りの右押し 6、名目、G1 の歩行の左押し 6 で cmp）。
