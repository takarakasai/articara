# G1 の走りの基準 WR07（2026-11-23、ユーザ確定＝§71 の案 1）

WR06（`BASELINE_RUN_WR06.md`）の走りに、遅れの予測器を足す。推定を、WBC 自身が直近 3 刻みに出した加速度で 3 制御周期（15 ms）先へ進めてから使う。走りの候補はこれと比べる。

- 設定: `wr07.sh` = `wr06.sh` ＋ `SENSE_PRED_TICKS=3`。
  - `SENSE_PRED_TICKS`（misa-biped `RobotModel::predict`）: 推定（胴の位置・姿勢・速度、関節の角度・速度）を `extracted.qddot` の履歴（古い順）で n 周期進める。胴は体の座標で積分する。JOINT_Q_EST の姿勢の段も、進めた推定を読む。
  - 遅れのある条件では、n を遅れの合計＋1 以上にする（センサー 40 ms なら `SENSE_DELAY_TICKS=8 SENSE_PRED_TICKS=10`、動力 10 ms なら `ACT_DELAY_TICKS=2 SENSE_PRED_TICKS=3`〜`4`）。
- バイナリ: `log/claude_g1rand_20260925/kyo46rs_walk_tu81`（articara に手元の misa-locomotion main 04ef595 を差し込んで組んだもの。04ef595 は 0a6fb85 ＋ 4 コミット、未 push）。ノブが未設定なら tu80 と軌道が一致（走り、走り＋10 ms の遅れ、G1 の歩行の左押し 6 で cmp）。misa-biped のテストは通る。
- **未了**: misa-locomotion の push と articara の依存の rev 上げ（push の確認待ち）。上げたら組み直して tu81 と一致を見る。
