# G1 の走りの基準 WR09（2026-11-25、ユーザ確定＝§74 の案 1）

WR08（`BASELINE_RUN_WR08.md`）の走りに、遅れの自動の見積もりを足す。予測器の長さを、走り出しの 1 s で同定した遅れの合計から決める。走りの候補はこれと比べる。

- 設定: `wr09.sh` = `wr08.sh` ＋ `SENSE_PRED_AUTO=16 SENSE_PRED_AUTO_ADD=3 SENSE_PRED_DITHER_T=1.0`。
  - `SENSE_PRED_AUTO`（misa-biped `walker.rs` の `LagEstimate`）: 測る関節ごとに ±`SENSE_PRED_DITHER`（既定 1 Nm）の符号の列をトルクに足し、観測した関節速度の差分との相関を遅れ 0〜16 刻みで平均（`SENSE_PRED_AUTO_TAU` 0.5 s）。山の位置を遅れの合計 L とし、予測を L＋3 刻みにする。見積もりが出るまで（0.5 s）は `SENSE_PRED_TICKS=3`。
  - `SENSE_PRED_DITHER_T=1.0`: 揺らぎと同定は 1 s で止め、見積もりを保持する（揺らぎを入れ続けると摩擦・雑音・荷物で損、§74）。
  - 遅れのない機体では L = 0 で予測 3 になり、WR08 と同じ長さ。違いは最初の 1 s の揺らぎだけ。
- バイナリ: `log/claude_g1rand_20260925/kyo46rs_walk_tu87`（articara に手元の misa-locomotion dbfe158 を差し込んで組んだもの。dbfe158 は 4ba73ef ＋ 2 コミット）。ノブが未設定なら tu84 と軌道が一致（走りの名目、遅れ 4＋予測 5 で cmp）。misa-biped のテストは通る。
- **未了**: misa-locomotion の push と articara の依存の rev 上げ（push の確認待ち）。上げたら組み直して tu87 と一致を見る。
