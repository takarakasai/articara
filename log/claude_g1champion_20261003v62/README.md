# G1 チャンピオン v6.2（2026-10-03）── v6 + 降段の 2 ノブ（`COM_LAND_EXTEND_DESC=0.25`、`COM_HEIGHT_DESC_LEAD=0.5`）

`controls.json` = v6（`log/claude_g1champion_20261003v6/`）に降段専用の 2 ノブを加えたもの。URDF は v6 と同じ。
**バイナリは新しい**（同梱の `kyo46rs_walk` = `log/claude_g1rand_20260925/kyo46rs_walk_desc3`）: 2 ノブは v6 同梱のバイナリには無く、
古いバイナリで走らせると黙って無視される。降段のスポーンには `SPAWN_Z_EXTRA=0.005` が要る（ベンチ側の設定、controls には含めない）。

- `COM_LAND_EXTEND_DESC=0.25`: 降段の遊脚の着地延長を昇段用の 1.08 s から 0.25 s に。昇段用の延長は踏み下ろした足を無荷重で待たせ、
  両脚支持 0.2 s で荷重が移らず次の遊脚で転倒していた。
- `COM_HEIGHT_DESC_LEAD=0.5`: 支持足より低い着地へ向かう遊脚（両脚支持ならその次の遊脚）の間、落差の半分だけ CoM 高さ参照を先に下げる。
  参照が台の高さに留まると踏み下ろす脚が脚長の 99.9% で 2 cm 届かず、かかとで立ったまま時間切れになり、最初に着く角の偶然で転倒していた。
  1.0 は沈み過ぎ（単発で転倒）、0.75 は −8 cm で 46/48。

どちらも降段の遊脚にしか効かず、**昇段・平地・押し・横は v6 とビット同一**（昇段 8 cm・後押し 11 N·s・6 cm 段の個体で `cmp` 一致）。
したがって v6 の成績表（std／wide／ホールドアウト／押し／横／低い段）はそのまま v6.2 の成績。
