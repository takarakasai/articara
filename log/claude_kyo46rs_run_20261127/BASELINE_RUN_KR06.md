# kyo46rs の走りの基準 KR06（2026-11-28、ユーザ確定）

KR04（`BASELINE_RUN_KR04.md`）から、kyo の歩行の基準 v4 から引き継いだ歩行専用の COP_LEASH を切ったもの。kyo46rs の走りの候補はこれと比べる。KR05 は電池の `kr05.sh` と名前が重なるので欠番。

- 設定: `kr06.sh` = `kr04.sh` ＋ `COP_LEASH=0`。新しいコードはない。
  - COP_LEASH は片足支持で足裏が傾くと QP の CoP の箱を測った CoP の ±5 mm に絞る。板の手前の縁をまたいだ支持足では測った CoP が縁の上（+26 mm）に張り付き、箱もそこに付いて動くので、踵を下ろす後ろ寄りの CoP を頼めず毎歩 0.18 → 0 m/s のブレーキになっていた。
- バイナリ: `log/claude_g1rand_20260925/kyo46rs_walk_tu88`（misa-locomotion dbfe158）。
- 名目（`kr06.sh`、各 16 本）: 種 1〜16、17〜32 とも 48 / 48（KR04 とバイト一致、平らな床では門が開かない）。
