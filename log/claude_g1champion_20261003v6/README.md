# G1 チャンピオン v6（2026-10-03）── v5.2 + 重み付き QP を段ゾーンでも使う（`WBC_WEIGHTED_OFF_STAIRS=0`）

`controls.json` = v5.2（`log/claude_g1champion_20260927v52/`）に `WBC_WEIGHTED_OFF_STAIRS=0` を加えたもの（1 ノブ）。URDF・バイナリは v5.2 と同じ（同梱）。

v5.2 までは段ゾーン（段の接近〜着地）で WBC を厳密カスケード（NullSpace HQP）に切り替えていた（2026-09-24 の「重み付き QP は段で 0/192」の測定に基づく）。
v6 では全域で重み付き単一 QP を使う。現構成（自由腕・MPC 権限・辞書式着地）ではその前提が消えており、段の成績はむしろ上がる。
副次効果: WBC の制御周期（5 ms）超過が 13〜28% → 1% 未満（厳密カスケードは毎 tick 10 ms 超だった）。
