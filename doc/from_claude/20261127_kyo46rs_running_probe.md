# kyo46rs の走りの下見（2026-11-27）

G1 の走りの基準 WR10（`doc/from_claude/20261125_g1_running_summary.md`）を kyo46rs に移す下見。ユーザ選択は「推奨の進め方で」= §76 の案 1（半日）。電池は `log/claude_kyo46rs_run_20261127/kr.sh`、数字は同じ所の `results.txt`。

## 結論

- **そのままでは 1 本も走らない。** 倒れる場所を 2 つ直して、2 歩で倒れていたものが 5〜9 歩まで走るようになった（T_FLIGHT 0.04 で 1／8 が完走）。
- **残る壁:** 3〜7 歩目の横の発散。着地の横のゲインと後ろ足の上げでは動かない。
- **kyo46rs の走りに要るもの:**
  - 重み付きの QP（`WBC_STRATEGY=weighted`）。
  - `COM_PREPLAN=0`。
  - その上で、横の安定の作り直し。

## 設定

kyo46rs の基準 v4 の controls に、WR10 の走りのキーを脚の比で縮めて足した。
- **脚の比:** 股から足裏まで約 0.30 m。G1 の 0.45 倍で、Froude 則で時間は 0.67 倍になる。
- **時間を縮めたもの:** T_SS 0.20、T_FLIGHT 0.04、RUN_FOOT_TAU、RUN_LAND_RAMP。
- **距離を縮めたもの:** 歩幅 0.032〜0.054、RUN_FOOT_MAX、RUN_FOOT_XI_MAX、PUSH_REPLAN 0.045、CP_RUN_CROSS_HOLD 0.009。
- **そのままのもの:** 比のノブ（RUN_FOOT_XI_G 1.5 など）。
- **v4 の controls から上書きしたもの:**
  - VX: v4 は 0.03 に固定しているので、G1 の既定と同じ STRIDE／T_SS にした。
  - INIT_JITTER 0.01: v4 の controls にはないので、足さないと種を変えても個体が同じになる。
- **バイナリ:** tu88。kyo46rs の v4 の平地と押しで、tu68 と出力がバイト単位で一致した。
- **遅れの自動の見積もり:** 揺らぎ 1 Nm は kyo の 6 Nm の駆動器には大きいので外した。

## 分かったこと

1. **刻みの下限:**
   - 空中なしで両脚支持を縮めると、T_SS 0.30 と 0.25 では両脚支持 0.02 s まで 8／8 で立つ（T_SS 0.25・両脚支持 0.02 だけ 5／8）。
   - T_SS 0.20 は両脚支持があっても 1〜2／8 で、kyo の遊脚がこの速さに追いつかない。
   - Froude 則どおりの 0.20 は使えず、T_SS 0.25〜0.30 が窓になる。
2. **根 1、階層型 QP が遊脚を落とす:**
   - 走りの最初の立ちは、計画上 −g の加速度（半正弦の押しの端）で始まる。
   - kyo の階層型 QP は、ここで降格して遊脚のタスクを落とす。遊脚は腰の落ちと同じ速さでしか縮まず、QP が力を割り当てていない足に 27 N（体重の 4 割）が載ったまま 0.17 s 離れない。
   - 遊脚のトルクは股・膝とも 1 Nm 前後で、上限（6／14 Nm）には遠い。力が足りないのではなく、指令が出ていない。
   - G1 も同じ瞬間に支持足の力が半分になるが、G1 は重み付きの QP で遊脚がすぐ上がる。
   - kyo を重み付き（G1 と同じ `WBCW_COM=100 WBCW_POSTURE=0.001`）にすると、離地は 0.1 s 早まり、最初の立ちは通る。
   - 接触の判定（CONTACT_ON_BW、CONTACT_ADMIT_*）は関係しない。離地の時刻はどの設定でも同じだった。
3. **根 2、COM_PREPLAN が鉛直の計画を壊す:**
   - kyo の v4 の COM_PREPLAN は、立ちを 0.30 s から 0.73 s に延ばす。
   - 半正弦の鉛直の計画の沈みは g·Ts² に比例するので、3 歩目で重心の目標が 17 cm 落ちる。
   - 走りでは COM_PREPLAN=0 にする必要がある。重み付きの QP と組み合わせて、倒れるまでの歩数が 2〜3 歩から 5〜9 歩に延びた。
   - 同じ組の速い歩行（T_SS 0.30、両脚支持 0.02）は 8／8 で 25 歩。
4. **鉛直の沈みは脚の長さによらない:**
   - 半正弦の計画の沈みは g と Ts だけで決まる。T_SS 0.30 では G1 も kyo も 3 cm 前後沈む。
   - 背の低い kyo には、高さとの比が倍近くになる（10% 対 6.6%）。
5. **残る崩れは横:**
   - 3〜7 歩目に、支持足の CoP が足裏の内側の端（半幅 30 mm）に張り付いたまま、DCM が遊脚の側へ逃げる。
   - 後ろ足（蹴り終わった足）は、次の立ちのはじめに 6〜14 N で床を引きずる。空中は名ばかりで、離地は 1 mm 程度。
   - 着地の横のゲイン（RUN_FOOT_K 0.2〜1.0、RUN_FOOT_XI_GY 0／1）は、上げるほど悪くなる。
   - 後ろ足を速く上げる設定（RUN_SWING_RISE 0.05／0.10、LIFT_H 0.045）も 5〜7 歩のまま。

## まだ確かめていないこと

- **横の発散の機構:**
  - 支持足が実際にどこへ着いたかは、TRAJ に足の位置の列がないので確かめていない。
  - DCM の式どおりなら、内側の端に CoP があれば止まるはずの位置で逃げている。着地が計画より内側にずれている可能性がある。
- **重み付きの QP で、kyo の歩行の基準（家族ベンチ）が保たれるかは未確認。** 走りの区間だけ重み付きにする切り替えが要るかもしれない。
- **2 本の完走が本当に浮いていたかは見ていない**（`flights.py -s`）。
