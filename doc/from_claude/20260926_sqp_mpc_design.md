## I-3. 分かったこと（因果の順）
1. **着地変数の価値は捕捉行にしかない。** 着地コストとモーメント結合だけでは、着地は角運動量の帳尻合わせに使われ、
   通常歩でも ±30–47 mm 揺れる（捕捉 0 で 8 N·s 前 2/24）。
2. **捕捉行は支配的でなければならない。** 箱 15/8 では捕捉 1e4 で歩き出しに転倒、1e5 で段崩壊、1e6 で可、1e7 で全滅。
   罰則重みの刃の上にある（等式化が本来の形）。
3. **解の 20 ms 交互反転の原因は計画の感度の欠落。** 着地を動かすと後ろ向き再帰の参照 DCM も ≈0.65 dp 動く。これを
   知らない捕捉行は次の solve で残差 −J dp を見て反対へ振る（利得 J/|b| が 1 を超える）。J を入れると反転は 17/280 →
   5/2795 tick に消え、wide holdout は 168→177、11 N·s 前は 37→40。
4. **時間の自由度は別途要る。** 着地変数は位置だけなので、11 N·s 前は時間調整なしでは 0/24。発見的調整を再計時器として
   残すと戻る。
5. **`MPC_COP_REF_CMD` は着地変数と相性が悪い**（DCM 則のシフトを MPC の参照へ足すと DS で過制動）。D 系では 0。

## 1. なぜ今の `wrench_mpc` では足配置が変数になれないか（測定済み）

| 事実 | 出典 |
|---|---|
| 制約（摩擦錐・CoP 箱・ねじり・fz）は足裏フレーム。接触位置を参照しない | §50 |
| 接触位置は角運動量行のモーメント腕 `skew(p − c_target)·R·f` にだけ入る。腕は**目標 CoM について凍結** | §50 |
| 角運動量は重み 2 の軟制約。着地 δp は残差を消す無償の手段になり箱の縁へ（重み無関係、45〜67 mm） | §50 |
| 角運動量を硬くすると v4 自体が崩れる（`MPC_W_MOM=2000` で 26.5 s 転倒） | §50 |
| MPC の予測は制約の中で「起こること」。片脚支持では CoP が 1 枚の足裏に閉じ、計画の折り返しを含まない | §49 |
| 地平延長（0.8 s）は 60/80 mm を 47/48 にするが 20 mm と前押しで退行 | §52 |

LIPM の結合「CoP は足の下 ⇒ 足の位置が使える水平力を決める」は、SRBD では
**L̇ ≈ 0 のとき**に限り F_xy ∝ (c − p_cop) として現れる。腕が凍結で L が軟制約の現状では現れない。

## 2. 変更点（4 つ、すべて既存の密 QP の拡張）

### 2a. 腕を予測 CoM について取り直す（SQP）
節点 k のモーメント腕を `p_k − c̄_k`（c̄_k は前回解の予測 CoM、`Solution::trajectory` に既にある）にする。
初回は現在 CoM で線形化。**1 tick 1 反復**（50 Hz で前回解を線形化点に使う = 実質 SQP）。
反復回数ノブ `MPC_SQP_ITERS`（既定 0 = 現状の凍結腕）。

### 2b. 角運動量を「変化率」で拘束する
現状は L を 0 へ追従（`momentum_weight`）。BD 型に近いのは **L̇_xy を小さく**すること（L 自体は歩行で振れてよい）。
節点ごとの L の差分 `(L_{k+1} − L_k)/dt` に重み `MPC_W_LDOT`（既定 0）。硬くしても v4 が崩れないかを
2a と同時に測る（2a なしで硬くしたのが §50 の 26.5 s 転倒）。

### 2c. 着地 δp を 2a の腕に入れる
`Landing`（実装済み）の線形化点を「計画荷重 × 凍結腕」から「前回解の力 × 予測 CoM 腕」に変える。
2a・2b が効いていれば δp は角運動量でなく CoM の水平力を通じて効く。
判定: §50 の「箔の縁に張り付く」が消え、|δp| が残差に比例して動くこと。地形は余裕付きコスト（§37）。

### 2d. 地平を次の着地まで
`STAIR_WRENCH_N` を段階的に 12→16。§52 の退行（20 mm・前押し）は 2a–2c と組み合わせて再測定
（地平延長単独の退行は「予測が長くなるほど凍結腕の誤差が積む」ことで説明でき、2a で消える可能性）。

## 8. 2a–2c の安価な経路の結論（09-27 01:15）── 閉じる
- 2a（腕を予測 CoM 周りに）: 単独で v4 に holdout −2.31。結合は作らない（縁 0.44 のまま）。
- 2b（L̇ 拘束）: 2a と組で δp を箱から外す（縁 0.44→0.03）が、\|δp\| は W と無関係に 30〜35 mm、決定は悪い。
- 2c（着地変数）: いかなる重みでも約 30 mm に張り付く。生存するのは箱を小さくして被害を限定した場合だけ。
**凍結接触フレームの SRBD では、着地はモーメント腕にしか入らず、L̇ を硬くしても「モーメントを消す足の位置」が
選ばれる。足配置の本来の役割（次の片脚支持で圧力点になり DCM を捕捉する）は地平内に次の片脚支持が無い限り現れない。**

### 残る本体（数日〜）

## 9. 本体・第 1 段（09-27 02:00 着手）── 着地を「次の支持の圧力点」として DCM 行に入れる
ξ を決定変数にせず、δp の**一次関数**として地平内の DCM を陽に書く:

- 捕捉コスト `w_cap |ξ_k(δp) − ξ_ref_k|²`（k ≥ first_node+1、ξ_ref は計画 `reference_dcm_schedule`）を行として追加。
- 既存の Landing（モーメント腕）はそのまま。これで δp は「モーメントを消す」でなく「DCM を計画に戻す」を主目的に持つ。

  1〜3 しか残らないので、効果が小さければ 2d（N=16）と組み合わせる。
knob: `MPC_LANDING_CAPTURE_W`（既定 0）。`Input::dcm_now`（計測 ξ）を追加。
実装（02:18）: `Config::landing_capture_weight`, `Input::dcm_now`, 捕捉行（a_k + B_k δp − ξ_ref_k）。単体テスト
`the_capture_rows_move_the_landing_toward_the_escaping_dcm`（DCM が計画より 4 cm 前 → δp.x > 0、モーメント結合単独と
逆向きで、重み付きなら捕捉が勝つ；w=0 で bit 一致）。walker `MPC_LANDING_CAPTURE_W`。3 系統 bit 同一。単発を下に。

## 10. 本体・第 2 段（09-27 09:00 着手）── 捕捉行に計画の感度 J を入れる
交互反転の原因仮説: 捕捉行は `a + b·dp = ξ_ref` を解くが、dp を適用すると計画（後ろ向き再帰）の ξ_ref 自体が
≈ J·dp（J≈0.65、CP_J_AUTO の実測）動く。次の解は残差 −J·dp を見て −J·dp/b を返し、閉ループ利得 J/|b| は
着地が地平の終端から ~3 節点以内（b ≈ 1−(1+ω dt)^m が小さい）で 1 を超える → 20 ms ごとの符号反転。
修正: `Input::reference_dcm_sensitivity`（節点ごとの 2×2、None＝現状でビット同一）を捕捉行に入れ
`a + (b − J)·dp = ξ_ref` にする。|b − J| ≥ J なので dp ≤ 誤差/J に有界（捕捉点ステップ調整そのもの）。
歩行側は `MPC_LANDING_CAPTURE_J=1` で、着地を 2 cm ずつ動かした計画を再構築して節点ごとに差分（毎 solve 2 回の再構築）。
単体テスト: J=0 は現状と一致、J=0.65 I は同符号でシフトが半分未満（28 本通過）。
