## 2. 再検証不要の確定事実

- **遊脚追従残差 14〜25mm の真因は `QD_CLAMP`**。QPへ渡す関節速度が ±5 rad/s で
  飽和していた(実速度 10〜31)。`QD_CLAMP=40` で行き過ぎ 27→1.3mm。
- **`TORQUE_SCALE` は no-op だった**(QP箱のみスケール、プラント未スケール)。修正済み。
- **接地測定が階段ボックス上で無効だった**(地面プレーンのみ計上)。修正済み。
- **下りの機序**: 遊脚の**踵が「今いる段の段鼻」に引っかかり、上段の縁に乗ったまま
  止まる**。段鼻クリアに必要なつま先下げは `arcsin(蹴上/足長)` = **32°**、
  実測は接地時点で **+16.6°** しか間に合っていない。
- **下りはリーチ律速ではない**。実測: 要求 167〜191mm vs 脚の限界 258mm(余裕67〜90mm)。
- **深しゃがみの律速は遊脚ロールの野放し**。`SWING_ROT=1` は遊脚ロールを拘束せず、
  しゃがみ60mmで無荷重側の足首ロールが +27°(通常±11°)→ 体重2倍の142N衝撃 → 転倒。
- **しゃがみ91mmでは脚が関節ストップ**: 膝 127.7°/130°、股 −94.7°/−100°。
  遊脚を持ち上げる余地が無い。
- **降段中の LIPM 剛性が 21% 柔らかすぎる**(ω²=32.9 vs 真値 g/h=39.7)。`VH_DCM` で修正。
- **質量配分**: 膝下 28.1%(人体12%、2.34x)、胴体 27.4%(50%、0.55x)、
  腕:脚の慣性比 6.1(人体~2.2)。足首軸高さ 27.6% of 脚長(人体~8%)。
- **足首**: 底屈のリーチ寄与は 31° で頭打ち(+13.7mm、以降は減少)。律速は背屈側。
- **腕の 110〜124° 振りは制御アロケーション**(`ARM_HOLD` が掛かった状態で振れる。
  上位の com/trunk/swing が null space 経由で腕を使い、保持はレベル5で抗えない)。

## 3. 【要注意】過去に「反証済み」とした実験 ── 表題を取り下げます

> ただし別レシピ・別課題での測定なので、厳密な再現試験ではなく
> **「現在の構成に一般化しない」**が正しい読みです。
> 各行は「その条件で悪かった単発結果」として読んでください。

## 4. 共有コードへ入れた変更(すべて既定で挙動不変)

**制御・モデル**
- `QD_CLAMP`(既定 5.0 = 互換): QP が見る関節速度クランプ
- `JLIM_Q_MARGIN` / `JLIM_V_FRAC`(既定 0 / 1.0): **CBF を機械限界の内側で動かす**。
  これが無いと ROM 拡大は「余裕」でなく「許可」になる(足首 ±20→±40 で悪化した件の解)
- `VH_DCM`(既定 **OFF**、階段時のみ有効): 可変高 LIPM(`dcm::com_accel_xy_vh`)
- `DAMPING_OVERRIDES="elbow=0.25,ankle_pitch=0.4"`: 関節別粘性(設計入力)
- `RigOptions::spawn_z_offset`: 高台スポーン

**階段**
- `STAIRS="n,riser,tread[,start]"`(負の蹴上=下り)、`STAIR_HALF_W`
- `STAIR_CROUCH`(既定 **0 = オプトイン**に変更。旧既定は flat ベンチまで沈めていた)
- `STAIR_CLIMB_RATE` / `STAIR_DESC_MIN` / `COM_DESC_DS` / `COM_DESC_XFER`
- `STAIR_SWING_WINDOWS` / `STAIR_TD_SINK` / `STAIR_TD_BIAS` / `STAIR_GAIT=pair`
- `STAIR_DESC_TOE` / `STAIR_DESC_TOE_START` / `STAIR_ANCHOR_FLAT` / `STAIR_ROLL_PATCH`
- `ZMP_ROLL`(`dcm::from_footsteps_rolled`): 単脚支持中の圧力を踵→爪先へ流す

**API**
- `contact_level(..., patch_mod)`: 足ごとに (sole_offset, cop_half) を差し替え
  (転がり接触。Codex の `stair_hybrid_contact` と統合済み)
- `gait::stair_swing_sink` / `stair_swing_windows` / `ContactPhase::frozen_clock`
- `ELBOW_KD` / `LAND_KD_ROT_BOOST`(反証済みだが残置、既定 0 / 1.0)
