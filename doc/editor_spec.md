# Articara ロボットモデルエディタ — 機能仕様

## 概要

ゼロからロボットモデルを作成・編集するために必要な機能の一覧と、
現状（2026-04 時点）における実装状況をまとめる。

---

## 1. モデル構造の構築（リンク・ジョイントの追加と編集）

| 機能 | 状態 | 備考 |
|------|------|------|
| 新規モデル作成 | ✅ 十分 | File → New で空モデル生成 |
| リンク＋ジョイント追加 | ✅ 十分 | ツリーパネルのフォームで親・名前・型・ジオメトリ・軸・リミット・色を指定 |
| リンク削除（サブツリーごと） | ✅ 十分 | 選択リンク＋子孫を一括削除、ルート保護あり |
| **リンク名・ジョイント名の変更** | ❌ 未実装 | 名前は読み取り専用表示のみ |
| **ジョイントタイプの変更** | ❌ 未実装 | 読み取り専用 |
| 親子関係の変更（リペアレント） | ❌ 未実装 | D&D も右クリックメニューもなし |
| リンク・サブツリーのコピー＆ペースト | ❌ 未実装 | Visual/Collision の個別 Duplicate のみ |
| 左右ミラー（対称コピー） | ❌ 未実装 | ヒューマノイド・多脚ロボットで必須 |
| **ツリーの右クリックコンテキストメニュー** | ❌ 未実装 | 操作の集約ポイントがない |
| ツリーのドラッグ＆ドロップ並べ替え | ❌ 未実装 | |

## 実装優先度

### 高（ゼロからの構築に必須）

1. **リンク名・ジョイント名のリネーム** — 名前を後から修正できないのは致命的
2. **ジョイントタイプの変更** — 追加後の修正不可は作業効率を大きく下げる
3. **ビジュアル→コリジョンの自動コピー** — 毎回手動で同じ形状を追加するのは非効率
4. **ツリーの右クリックメニュー** — 上記操作のアクセスポイントとして必要

### 中（効率化に重要）

5. リンク・サブツリーのコピー＆ペースト
6. 左右ミラー
7. ミミックジョイント UI
8. damping/friction 対応

### 低（あると嬉しい）

9. 慣性テンソル楕円体表示
10. ジョイント可動域可視化
11. マテリアルパレット管理
12. Gazebo 拡張タグ保存
